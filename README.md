## 팀원
-20221 이한규
## 질문
공장 센서들의 값이 높을수록 정말 불량 반도체가 나올 확률이 높아지는가
## 왜 이 주제인가
반도체에 관심이 많고 반도체 공장에서 장비 고장이 얼마나 손해인지 알고 있음.
센서들의 값이 높을수록 불량이 나올 확률이 높다고 생각함.
## 데이터
캐글 데이터 이름:Semiconductor Wafer Defect Classification Dataset
- 기간·행 수·열 수:5000행 9열
- 사용한 열:temperature_c (온도), pressure_torr (압력), gas_flow_sccm (가스 유량), etch_rate_nm_min (식각률), voltage_v (전압), current_ma (전류), defect_label (결함 여부)
  
- 개인 단위 정보 없음 확인: 예

## 지표
데이터에 불량인 데이터가 극히 적어서 재현율을 써서 실제 불량중 모델이 잡아낸 비율을 보겠다.

## 데이터
센서들의 값이 높을수록 불량이 많을거라는 내 예측과 달린 불량 7건은 모두 평균보다 압력이 낮았다.온도는 7건 중 4건만 평균보다 높았다.식각률은 대부분 평균보다 높다.데이터에 불량이 적어 온도나 식각률은 착각일 확률이 높다.
이 데이터는 연구 학습용으로 만든 데이터라 진짜 데이터는 아니다.따라서 진짜 환경과는 다를 수 있다는 한계가 있다.
